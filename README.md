An AI-assisted travel planning and booking application designed to help users create smarter and more personalised travel experiences.

WanderWise AI combines itinerary generation, booking assistance, route planning, and travel recommendations into an interactive Streamlit application powered by AI.

---

## Features

- Multi-destination travel planning
- AI-generated personalised itineraries
- Flight, hotel, and vehicle booking assistance
- Road trip and camping support
- Arrival and transport recommendations
- Screenshot-based booking information extraction
- Interactive Streamlit user interface
- Modular AI agent structure for planning workflows

---

## Tech Stack

- Python
- Streamlit
- OpenAI API
- Pandas
- Plotly
- PIL / Image Processing
- Modular AI Agent Architecture

---

## Project Highlights

- Designed and developed an AI-assisted travel planning workflow
- Integrated structured user inputs with AI-generated recommendations
- Built modular planning and booking components for scalability
- Implemented screenshot parsing to extract travel information from uploaded images
- Applied prompt engineering techniques to improve itinerary quality and usability
